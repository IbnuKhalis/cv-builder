🖨️ Pemeriksaan Pra-Ekspor & Panduan Cetak PDF

Periksa ringkasan kesiapan dokumen Anda di bawah ini sebelum menyimpan sebagai PDF A4:

  1. Destination / Tujuan: Pilih Save as PDF atau Simpan sebagai PDF.
  2. Paper Size / Ukuran Kertas: Pastikan berukuran A4.
  3. Margins / Margin: Pilih Default atau None.
  4. Headers and Footers: Hilangkan centang (Uncheck) opsi Headers and footers agar tanggal dan URL browser tidak ikut tercetak.
